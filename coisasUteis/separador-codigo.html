Organizador de Texto e Código

Cole um texto com vários trechos de código misturados e o site separará automaticamente cada bloco de código do texto comum.

Entrada

O organizador detecta blocos de código por padrões como chaves, pontos e vírgulas, palavras reservadas e indentação. Use "Por ; (blocos separados)" para criar um espaço maior entre cada trecho separado por ponto e vírgula.

Saída organizada

Após processar, aqui aparecerão blocos de texto e blocos de código separados.
